Mar-A-Lavitch Pool Management

Everything it takes to run a swim club — staffing, chemical compliance, the deck, and the snack bar — in one small server and two web apps.

Management console

Schedule shifts, watch the chemical log, see who's on site, run reports and arrange the deck. Built for a desktop in the office.

Mar-A-Lavitch Staff

What the lifeguards carry: clock in, log a reading, take breaks, seat guests and ring up orders. Phone-first, installable, works offline.

Open the demo

This is a demo. Every employee, shift, and punch you'll see is invented — the club's real data lives on its own server and never reaches GitHub. Poke at anything: ring up an order, clock someone in, drag a chair. Changes save to your browser alone, and clearing the site's storage puts it back to the start. Best on a phone for the staff app, a wide window for management.

What it does

  • Chemical logs graded pass / warn / fail, with CSV export for the health department
  • Shift scheduling with bulk creation, requests, and confirmations
  • Clock in/out with a photo, a live on-site board, and hours summaries
  • Breaks management assigns and staff start from their own phone
  • Deck map of loungers and cabanas, identical on phone and desktop
  • Reservations & waitlist that seat straight onto the map
  • Snack-bar POS — menu, tickets, payment, settle, and void
  • Multiple pools, each with its own status, tax rate, and layout
No frameworks, no build step, no database — pure Python standard library and single-file HTML apps.
